# Mídia real dos projetos

Para substituir a representação conceitual por captura/vídeo real, adicione os arquivos aqui e
referencie-os em `src/features/home/projectMedia.ts` (campos `desktop` e/ou `mobile`).

- Especificação completa e nomes exatos de arquivo: `ASSETS_PENDENTES.md` (raiz).
- Imagem desktop: proporção 16:10, 1920×1200, WebP.
- Imagem celular: proporção 433:882, 866×1764.
- Vídeo: MP4 H.264 (+ WebM opcional), sem áudio, ≤ 8 s em loop, ≤ 3 MB, com poster.
- Quando houver mídia real, o rótulo "Representação conceitual" deixa de ser exibido para aquela tela.
- Não use capturas de interfaces fictícias como se fossem reais.
